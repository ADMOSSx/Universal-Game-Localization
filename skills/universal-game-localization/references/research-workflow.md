# Research workflow

1. Write down a hypothesis about engine/format and confidence.
2. Find primary documentation or a reputable tool repository.
3. Verify tool compatibility with game version/platform.
4. Record source URL, access date, license, release/version, requirements, and risk.
5. Separate tool discovered, downloaded, installed, and tested statuses.
6. For community tools, inspect release page and repository activity; avoid random download mirrors.
7. Do not download executables automatically. Ask for permission before installing/running.
8. If extraction is blocked, provide a reproducible manual path and list exact files needed.
9. If web access is unavailable, mark research UNKNOWN; don't fabricate URLs or tool details.
