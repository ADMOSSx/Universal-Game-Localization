INSTALL (OpenCode Desktop / Windows)

1. Unzip the downloaded package.
2. Open the extracted folder.
3. Copy the folder `universal-game-localization` into:
   %USERPROFILE%\.config\opencode\skills\
   (create the `skills` folder if it is missing).
4. Confirm this file exists:
   %USERPROFILE%\.config\opencode\skills\universal-game-localization\SKILL.md
5. Restart OpenCode Desktop.
6. Start a conversation and write, for example:
   Use the universal-game-localization skill.
   Analyze this game folder: D:\Games\GAME_NAME
   Prepare everything for Arabic localization and create a Claude-ready package.
   Do not alter the original game.

Optional check (needs Python 3.8+):
   cd %USERPROFILE%\.config\opencode\skills\universal-game-localization
   python scripts\selftest.py        -> should end with SELFTEST PASSED

Alternative: install per project under
   .opencode\skills\universal-game-localization\SKILL.md
