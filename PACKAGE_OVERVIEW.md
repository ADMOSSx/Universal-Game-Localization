# ADMOSS Universal Game Localization Skill - v0.3.0 (lean)

Portable OpenCode skill (SKILL.md format), designed for free/low token limits. Reusable and engine-aware; does not promise every game is supported.

Start with `universal-game-localization/README.md` and `INSTALL_WINDOWS.txt`. Then run `python scripts\selftest.py` inside the skill folder to confirm the helpers work.
